### API для работы с параметрами конкретного продукта

1. Получение списка свойств продукта, создание нового свойства у продукта: 
***'api/product_property'***
2. Получение деталей свойства конкретного продукта, обновление параметров этого свойства, 
удаление свойства у продукта: ***'api/product_property/<int:pk>/'***

[*] Только авторизованные пользователи
