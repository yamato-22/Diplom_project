### API для работы с заказами (orders)

1. Получение списка заказов пользователя: ***'api/order'***
2. Получение заказов пользователя по id: ***'api/order/<int:pk>/'***
3. Создание нового заказа: ***'api/order/create/'***
4. Добавление товара в заказ: ***'api/order/add-product/'***
5. Удаление товара из заказа: ***'api/orders/remove-product/<int:product_id>/'***
6. Получение детальной информации по заказу: ***'api/order/detail/<int:order_id>/'***
7. Подтверждение заказа покупателем: ***'api/order/buyer/confirm/<int:order_id>/'***
8. Изменение статуса заказа поставщиком: 
***'api/orders/supplier/change-status/<int:order_id>/'***

[*] Все запросы могут выполнять только авторизованные пользователи.
