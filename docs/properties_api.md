### API для работы со свойствами товаров (property)

1. Получение списка свойств, создание нового свойства: 
***'api/property/'***
2. Получение деталей конкретного свойства, обновление параметров свойства, 
удаление свойства: ***'api/property/<int:pk>/'***

[*] Get запросы могут выполнять любые, в том числе, не авторизованные 
пользователи, Запросы POST, PATCH, PUT, DELETE могут выполнять только 
авторизованные пользователи.
