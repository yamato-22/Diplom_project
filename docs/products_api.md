### API для работы с товарами (product)

1. Получение списка товаров, создание нового товара: 
***'api/company/'***
2. Получение данных конкретного товара, обновление данных товара, 
удаление товара: ***'api/productdetail/<int:pk>/'***
3. Получение детальной информации о товаре, включая все его свойства(properties)
***'api/productdetail/<int:pk>/'***

[*] Get запросы могут выполнять любые, в том числе, не авторизованные 
пользователи, Запросы POST, PATCH, PUT, DELETE могут выполнять только 
авторизованные пользователи.
