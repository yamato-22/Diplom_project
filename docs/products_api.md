### API для работы с товарами (product)

1. Получение списка компаний(поставщиков), создание новой компании: 
***'api/company/'***
2. Получение деталей конкретной компании, обновление данных о компании, 
удаление компании: ***'api/company/<int:company_id>/'***

[*] Только авторизованные пользователи
