### API для работы с пользователями

1. Регистрация нового пользователя: ***'api/user/register'***
2. Получение данных о пользователе, обновление данных пользователя: 
***'api/user/retrieveupdate'***
3. Изменение пароля пользователя: ***'api/user/changepassword'***
4. Создание access токена для пользователя: ***'api/user/token'***
5. Обновление access токена пользователя через механизм refreh токена: 
***'api/user/token/refresh'***

[*] Все действия, кроме первичной регистрации, требуют авторизации
