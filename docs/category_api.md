### API для работы с категориями товаров (category)

1. Получение списка категорий, создание новой категории: 
***'api/category/'***
2. Получение деталей конкретной категории, обновление данных категории, 
удаление категории: ***'api/category/<int:pk>/'***

[*] Get запросы могут выполнять любые, в том числе, не авторизованные 
пользователи, Запросы POST, PATCH, PUT, DELETE могут выполнять только 
авторизованные пользователи.
