### API для работы с компаниями (поставщиками)

1. Получение списка компаний(поставщиков), создание новой компании: 
***'api/company/'***
2. Получение деталей конкретной компании, обновление данных о компании, 
удаление компании: ***'api/company/<int:company_id>/'***

[*] Get запросы могут выполнять любые, в том числе, не авторизованные 
пользователи, Запросы POST, PATCH, PUT, DELETE могут выполнять только 
авторизованные пользователи.
